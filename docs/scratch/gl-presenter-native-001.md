# Native OpenGL presenter

Phase 2a of the November 24 OpenGL request adds `--renderer software|gl|auto` to ordinary startup. Software is the default. `auto` opens a fresh software window if GL initialization fails, and explicit `gl` reports the failure. The selector logs the requested and actual backend once per connected session. [Playtest request](../playtest/2026-11-24-opengl-request.md) · [Renderer plan](../OPENGL_PLAN.md)

`runApplication` passes the startup selection to `SdlWindow::ensure`. The native presenter owns one SDL OpenGL window and context from menu through results. `runFrontendWindow` uploads `FrontendSession::composeFrame()` for menu, map and results. `runApplicationLeg` uploads `DisplayedFrameQueries::composedImage()` in play and the raster image in scene-only mode. The standalone map shares the presenter. Input continues through `gameCoordinates` and the existing CPU pick queries.

The review traced the initial `runApplicationLeg` draw through `SoftwareLevelRaster::drawTubeBatch` and `RasterCommandBatch::flush` to the lazy `rasterRows()` pool. The serial scope originally began after that draw. For `gl` and `auto`, the level leg now resolves presentation and applies the actual backend's raster policy before preparing and drawing the first scene. Default software keeps its window setup after the initial draw. Auto fallback uses the software raster policy, and headless screenshots skip presentation setup. The native factory requests core 3.3 before window creation and loads its entry points through SDL. It checks the version and profile, the double-buffered RGB drawable and the logical RGBA8 framebuffer. The shared shader body receives a desktop or ES preamble. The source texture receives top-down straight-alpha bytes and uses nearest sampling. Requested `--window-shot` and source comparison checkpoints draw into the RGBA8 target, read with pack alignment 1 and flip rows once. The AMD Radeon RX 9070 XT returned core 3.3, RGB 8/8/8 and swap interval 0. [Native startup](../../build/gl-presenter-native-001/initial-raster/startup-gl-1x-windows.log)
