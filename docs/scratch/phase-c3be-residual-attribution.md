raster samples and final visible influence. Source review confirms coverage,
depth and alpha rejection before color writes in SceneRaster; this pass did
**not** measure their per-source aggregate. Suppression can also affect final
color through depth-only earlier writes. It cannot distinguish a missing or
rejected native source from software geometry/material/composition disagreement.

Thus the directive's full causal diagnosis is **incomplete**, not certified
impossible offline. The concrete missing software join is primary source-record
identity -> accepted raster/depth/color writes -> final influence in the
primary-sensitive error pixels. The frame map's earliest unclosed native edge
remains actual scene admission/cache/clipping and effective resource/state for
the matched repair4 frame; the conditional retained trees do not close it.

**No correction is justified by this packet.** If separately approved, prioritize
a bounded primary-source coverage/final-influence comparison using these saved
supports, then compare the implicated intermediate against retained independent
evidence or specify its exact unavailable native counterpart. Do not presume a

or select parameters/removals by screenshot score. Both authorized attempts are
