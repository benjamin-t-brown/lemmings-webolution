# Recovery ledger

Target: installed reference `Lemmings Revolution.exe`, SHA-256
`32675bdb49866e76502713251fdfd2b09078c2481c72ca22ff68ebf4b3737a2f`.

Status wording distinguishes four tiers, weakest first: ported from decompiler
output and not yet exercised; unit checked; compared against the original bytes
offline through a mapping helper in `tools/`; and compared against the original
bytes **in-process**, inside the running game through the harness in `hooks/`
(see [the hybrid runtime notes](../HYBRID_RUNTIME.md) and
[its evidence record](evidence/hook_harness.md)). In-process comparison is the
strongest tier because the original code is mapped at its recorded address in a
real process. None of the tiers implies gameplay has exercised the routine;
that is stated separately where observed.
