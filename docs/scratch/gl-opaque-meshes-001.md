# Native opaque mesh comparison

The November 24 OpenGL request moved this phase ahead of playable v1. `--compare-opaque DIR` enables native GL and saves cumulative Primary, LegacyUnattributed and Tube snapshots at level frame 0, the first terrain edit, F10, and explicitly requested `--compare-frame N` checkpoints. The window presents the complete software-composed frame, including HUD, effects and cursor. Software remains the default. [Playtest request](../playtest/2026-11-24-opengl-request.md) · [OpenGL plan](../OPENGL_PLAN.md)

`runApplicationLeg` prepares the three mesh passes once. `SoftwareLevelRaster` consumes the complete prepared scene. `OpaqueSceneComparison` submits the admitted mesh ranges to `NativeOpaqueGpu` on the presentation context thread and reuses the software triangle routines for reference snapshots of the same passes. The native backend keeps indexed vertex data for each backdrop node and tube block/bank for the leg. It compares packed vertex and index records independently before uploading, retaining corner attributes, order and UV seams. The shader evaluates inclusive coverage at logical pixel centres with clip W of 1. It interpolates reciprocal-W attributes and affine comparison depth separately, uses byte-domain filtering, and reads colour, owner and encoded depth only at checkpoints. The per-frame submitted depth interval maps monotonically into `[0, 0.5]`, with 1 reserved for infinity. The shader consumes the clone's existing bank order and depth bias. The original device's inherited depth and clipping state remains open. The RX 9070 XT driver `26.10.1.261109` used the precise binary64 shader and binary32 depth storage. Across both levels, all 51 pass snapshots matched both finite coverage and visible coverage contributed by each pass. Each filtered interior stayed within one byte per RGB channel. No depth sample exceeded its recorded error bound and no depths were out of range.
