# Playtest 1, 2026-11-12

Human play of the clone by the user: about an hour, optimized build of commit
`721c64e` (`build/cmake/gcc-release/webolution.exe`), ordinary frontend route, fresh
normal save. Levels reached: the first map nodes, including the Climber, Floater,
Bomber, Builder and Basher tutorials. This is clone observation by a person. It is
not original-comparison evidence; "expected" is the player's expectation of the game.

The first debug build was too slow to play (software renderer, unoptimized).
Playtests use an optimized build.

scripted win alone.
