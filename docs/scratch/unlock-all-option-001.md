# Unlock all levels in Options

Playtest 17 requested the desktop launcher’s all-level map in the browser after the user won **Make Mine a Large One** (`E18_KF_2`, node 26). The desktop launcher set `WEBOLUTION_UNLOCK_ALL=1`. The browser Options page had no corresponding control, so normal progress could leave that route locked. [Playtest 17 browser check](../playtest/2026-11-18-playtest-17.md) · [Incoming map and menu sources](../../build/unlock-all-option-001/git-show/)

The clone-only **Unlock all levels (Off/On)** row is shared by main-menu and in-level Options. Click or Return toggles it, and Left and Right set Off and On. Accept applies the edit and Escape discards it. The existing in-level O shortcut accepts the edit and leaves the level paused. The row wording and layout are provisional clone choices. [Menu rendering and hit targets](../../src/app/SoundMenu.cpp) · [Input and edit handling](../../src/app/FrontendSession.cpp)

`runApplication` loads the sidecar and passes it to `FrontendSession::configureSound` before showing the frontend. `finishSoundEdit` writes accepted edits through the existing `SaveSink` to `SoundSettings.dat`. Version 2 stores `[2, music, sfx, unlock]`. Version 1 keeps both volumes and defaults the toggle to Off. On a write error the prior file survives and a later Accept retries the in-memory edit. Web uses the existing IDBFS mount and asynchronous file replacement. [Codec](../../src/save/SoundSettings.cpp) · [Web mount](../../src/web/webolution.html) · [Web replacement](../../src/web/Browser.cpp)

`FrontendSession::refreshMap` passes the actual completion flags to `MapScene::setProgress` when the accepted toggle changes, after a win, and after New Game. The environment override still forces availability. State 3 draws the yellow available sprite and permits selection. State 2 takes precedence for won nodes. Turning the option off restores saved progression with the environment override unset. Option edits write only the settings sidecar. [Map preparation and picking](../../src/app/MapScene.cpp) · [Launcher override](../../scripts/Play-Clone.ps1)
