# Keyboard shortcuts in Options

Playtest 30 W3 requested a place to look up the clone's keyboard controls. The Options row now sits directly above Accept Changes And Exit. The Windows clone probe opened Options from the main menu and from the level menu in Just Climb (`MM_CLIMB_002`, node 0), entered from the map. [Playtest 30 W3](../playtest/2026-11-23-playtest-30.md)

`FrontendWindow` and the level-menu branch in `runApplicationLeg` route Options input through `handleSoundOptionsInput` and `FrontendSession`. `SoundMenu` lays out and hit-tests the new plate alongside the existing Options rows. `shell::Frontend` switches to the shortcuts page under the same caller and preserves Options focus. Enter, Escape and the Back plate return to that row with pending values intact. The Windows probe checked the existing Accept write and Escape rollback using a private sidecar. It also checked that the level tick stayed frozen while the page was open. [Probe log](../../build/keyboard-shortcuts-001/probe.log)

The level loop forwards Keypad 4 and 6 to `CameraController::update`. Those keys change camera yaw during a drag. Outside a drag they change the controller's internal cursor coordinate, while the visible cursor uses the SDL pointer or touch position. The level key handler accepts 1 to 8 for stocked skills in play and standard pause because its guard excludes only Examine Pause. `SoundMenu::renderShortcuts` now describes the keypad action under Camera and lists 1 to 8 under both Level Play and Standard Pause. The examine keys enter Examine Pause from standard pause and resume play from Examine Pause.
