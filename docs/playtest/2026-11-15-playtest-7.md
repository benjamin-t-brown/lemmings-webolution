# Playtest 7, 2026-11-15

Human play by the user on a release build of commit c59fe2b (release-rate control, replay
recorder, death particles, yippee cue), launched with scripts/Play-Clone.ps1 on the separate
playtest save. First playtest under the smoke gate and the first with input recording.

## Levels won
Map nodes 0 to 11, one attempt each, 23:33 to 23:44: Just Climb, Just Float, Just Bomb, Just
Block, Just Build, Just Mine, Just Bash, Just Dig, Introducing - Water Lemmings, Block And Bomb,
Bash and Mine, Sometimes up..sometimes down. The user reported completing all levels up to
"Sometimes Up Sometimes Down"; the recording shows that level won too (93 saved of 50 required).

All twelve recordings replay headless to the same result (PASS, won=1) and are promoted to
docs/playtest/replays/2026-11-15-playtest-7/. A replay is clone regression evidence only.

## Reported by the user
"It's pretty good."
- W1: some minor z clipping problems. The user expects a move to OpenGL to fix them. Deferred,
  not queued.
- W2 (confirms playtest 6 V7): clicking individual lemmings is much cleaner.
- W3: in the original the user believes clicking the spawner box in the level changes how fast
  it drops lemmings, rather than a separate panel button, so different spawner boxes can run at
  different rates. The clone's RATE panel box (release-rate-control-001) misread playtest 6 V8.
- W4: an exploding lemming has particles under Armageddon but not when the Bomber skill is used.
  death-particles-001 was accepted on a scripted Bomber image; the playtest overrules it.
- W5: lemmings have no animation jumping into the balloon; they just disappear.

Not commented on: fatal-fall splat, yippee cue, release-rate limits.

Queued: bomber-skill-particles-001 (W4), exit-jump-anim-001 (W5), hatch-click-rate-001 (W3).

## Correction, same day
The user played again and withdrew W4: the Bomber skill does make the lemming explode with
particles. W4 is closed as not a defect, bomber-skill-particles-001 was removed from the queue
before it ran, and death-particles-001's acceptance stands.
