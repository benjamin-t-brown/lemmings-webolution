## Reported by the user
- D1: after a right-drag, the pointer stays frozen during the drag (correct) but jumps to a new
  position on the next mouse movement after release. The user called this the biggest problem: it
  makes the game unplayable. Cause: SDL keeps moving its own cursor during relative mouse mode and
  restores it there when the mode ends. Fixed directly by the lead in src/app/main.cpp (warp the
  cursor back to the frozen pointer on right-button release); not yet confirmed by the user.
- D2: Options does nothing, from the main menu or the in-level menu. Not a regression: the clone
  never implemented it (main-menu row 3 and the in-level Options row are both consumed without
  opening a screen; docs/STATUS.md lists options parity as open). Queued as options-menu-001.
- D3: sound stopped working. Nothing under src/audio changed since playtest 13, when sound worked;
  the release build opens its audio device with no diagnostic and its volumes are fixed in code.
  The user was asked to check the Windows volume mixer and output device, and then reported sound
  working with no clone change. Closed; not a clone defect.
- D4: on Wandering Free (MM_ALL_8_002), builder bricks near the top of the cylinder looked flat
  although lemmings walked on them correctly. Measured from attempt 8
  (MM_ALL_8_002-1795028567101239000-8.replay): the second staircase spans grid rows 76..87, and
  TubeScene::syncTerrain created new corners with coordinate height 96, which pins every new
  corner in rows 80..96 to height 80. The original uses world+28 = 112 (43D2F9/43D334, retained in
  docs/scratch/steel-blast-dig-tilt-001.md, which applied it to steel corners only). Fixed directly
  by the lead in src/app/TubeScene.cpp (112 for every new corner); new corners now follow their
  rows. Smoke passed (95 main, 84 recovery). Not yet confirmed by the user.

- D6: hovering the main menu does not highlight the row under the pointer. Not a regression: the
  committed frontend stores the pointer on motion but changes the row highlight only on click or
  UP/DOWN. Queued as menu-hover-001, after options-menu-001 (same input files).
