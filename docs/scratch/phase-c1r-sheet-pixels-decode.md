Queue `c1r-sheet-pixels-decode`. Worker packet `build/tmp/c1r-sheet-pixels-decode/round-note.md`, `prediction.md`, scripts, decoded sheets and crops. Unicorn on the Mac venv for the decoder; capstone via `read_steppers.py --at` on mouv. REA not used; no game, no debugger, no Frida, no stock start. Dispatched 12:50 MDT, packet ~12:54, landed 12:56.

## Result

- **Member layout (READ).** Byte 0 of a sheet member is the **chunk count**, not a method tag (c1p's "leading tag `02`" was the count). Per chunk: u16 length (includes the 5-byte head), u16 output size, u8 type, payload. Caller loop `0x450270..0x450449`: type 3 is a raw copy (`0x4503B3`), type 4 calls `0x467DE8` (`cmp eax,4` at `0x4503C5`, call `0x4503FD`, check `eax == outsize` at `0x450405`); anything else is a logged error. Chunk outputs concatenate into one BMP. Example HI21 (member 523, 37,589 B): chunks 36,314 -> 60,000 and 1,274 -> 2,518, total 62,518 = the BMP size field.
- **Decoder (READ by emulation of the exe's own bytes).** `0x467DE8` is the font's decoder too. All 115 `TEXTURES\SHEETS\$LEMSHEET*.BMP` members decode, start `BM`, and carry a size field equal to the decoded length. Branch internals of `0x467DE8` were run as a black box, not traced.
- **Seven generic icons (READ).** Six sheets (Hi21, Hi4, Hi11, Hi13, Hi16, Hi5), all 256 wide, 8 bpp. The frame rectangle is x in `[f8, fc)`, y in `[f4, f0)` of the `.spr` frame (c1p's `f0..fc` are y1, y0, x0, x1). UV doubles equal rect / sheet size to 1e-9 for all seven. Non-index-0 pixels in the crops: 679/690, 2552/2556, 1322/1330, 1328/1332, 1073/1080, 2300/2303, 689/690 for icons 0, 1, 3, 4, 5, 6, 7. Icons 0 and 7 share Hi21.
- **Icons 2, 8, 9 (PARTLY READ).** They do not use the Hi sheets: `GREYICONS.SPR`, `BLACKICONS.SPR`, `ADDITIVEICONS.SPR` frames match c1l's live frame records 3/3 on geometry and UV. Textures `$Greyscale0` (24 bpp, 20 x 25), `_BlackIcons0` (24 bpp), `~Additive0` (4 bpp) decode through the same routine. The record names do not describe the art (icon 8's record is `questionmark`, its crop a double chevron).
- **UNREAD (named remainder).** Palette-index-0 colour key / alpha at texture creation `0x47218A`; blend `0x46D5F3`; tint writers; the draw x, y (c1s); texture-id assignment `0x45FE10` / `0x4607D0`; the Hi/Lo choice `[0x58CD80+0xCC]`; whether the loader flips rows (crops treat the BMP as bottom-up and the art is upright).
