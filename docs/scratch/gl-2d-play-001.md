# gl-2d-play-001

Phase 7 of the November 24 OpenGL request connects native GL play from the menu through the map, Just Climb (`MM_CLIMB_002`), results and Continue. The previous native path uploaded the completed software scene. `runFrontendWindow` now supplies revisioned pages and prepared tooltip, sound and cursor draws. `runApplicationLeg` submits the prepared 3D scene to GL, resolves hover with GPU depth and ownership, and passes the colour and depth textures to the same native compositor. It draws the HUD, panel, fuse labels, cues, menu, cursor and caption in order. A nearest blit presents the logical target. PNGs and `inspectLevelFrame` read that target on demand. The CPU still owns the indexed map mask, layout, input and simulation. Software is the startup default and supplies explicit comparison frames and C3 write-event traces. ## Native results

- The existing level-return test route, adapted to feed scaled SDL input to a real GL window, won Just Climb with 10 saved and 1 required, showed loss results and Retry, and confirmed map progress. At 640×480, 1280×960 and 1920×1440, all 30 menu, confirmation, map and results comparisons were exact. The 30 level comparisons had a maximum error of one byte across at most eight pixels per frame. The host's 2560×1392 usable desktop normally clamps the request to 2×. A probe-only SDL bounds override permitted the oversized 3× client and verified its real drawable size.
