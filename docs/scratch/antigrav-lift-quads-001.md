# Anti-grav lift quad edges

Playtest 23 N3 reported visible quad edges on **Designed with love** (`M11_KF_1`, node 33). The clone's pre-change framebuffer shows vertical streaks through the bright beam immediately above the lift panel at yaw 46. The exact cause of those streaks and which edges the original visibly shows remain unverified. [Playtest ledger](../playtest/2026-11-20-playtest-23.md) · [Desktop framebuffer](../../build/antigrav-lift-quads-001/native-before-yaw46.png) · [Camera](../../build/antigrav-lift-quads-001/camera-yaw46.json)

## Static findings

- The three placed lift roots are at LVL offsets `0xFBA34`, `0x10243B` and `0x108E42`. Each contains two beam and two reflection kind-7 meshes with 16 records apiece. Authored alpha ranges from 0 to 255 for beam vertices and 0 to 128 for reflections. The base archive's 32×32 `Models\anti_grav\~shaft_antigrav` BMP has 512 black texels and no `.ALF`. This geometry can produce a smooth fade where the authored contribution reaches zero. The visible outline of the lit portions depends on the texture samples and depth and fill behavior. The edge texels and the effective uploaded alpha were not established. [Material census](../../build/flipper-effect-blend-001/materials.tsv) · [Texture census](../../build/flipper-effect-blend-001/textures.tsv) · [Upload instructions](../../build/flipper-effect-blend-001/rea/472f99-asm.json)
- On the registered x86 EXE (SHA-256 `32675bdb49866e76502713251fdfd2b09078c2481c72ca22ff68ebf4b3737a2f`), `0x43A4EC` draws the tube, restores combined U/V wrap at `0x43A908`, then walks the shared gadget and lemming list in reverse insertion order. The lift draw callback is `0x4323EB`, the lemming callback is `0x42EEF2`, and both dispatch from `0x43A9BB` or `0x43AA47`. Filter state is inherited. The retained trace shows `0x470F29` requests linear for MIN/MAG when enabled and supported, and point otherwise. `0x47261F` disables alpha test at `0x4728DC` and modulates texture and diffuse alpha for flag 4. Selector 3 requests SRCALPHA/ONE in `0x414D80`. The retained executable scan finds no explicit Z-enable, Z-function or Z-write requests. Effective wrapper depth state is unknown. REA closed without a snapshot. - The clone's `runApplicationLeg → scheduleSceneFrame → BackdropScene::renderStage(GadgetEffect) → rasterizeSceneTriangle` already uses linear wrap, authored diffuse alpha and SRCALPHA/ONE after the tube. It supplies opaque texture alpha, uses strict Less with depth writes on, and runs the lift pass ahead of actor composition. `SceneBillboardSource` handles a different node type. Depth rejection among overlapping lift faces and shared-edge coverage remain hypotheses. Desktop and Wasm compile the same scene rasterizer. ## Checks and blocker

The registered native `webolution` build and headless phase-zero framebuffer at yaw 46 succeeded. The browser build reached final emit with the existing project-local SDK library cache and SDK SDL port directory. Windows denied replacement of `build/cmake/emscripten-release/webolution.js`, and `Get-Acl` on that path also returned `UnauthorizedAccessException`. The linked `.wasm` timestamp advanced while the `.js` timestamp did not. Treat that pair as an incomplete build. The denied link was not retried. This report is the only tracked file changed. Paired crops, Node frames, promoted replays and the implementation remain outstanding. Supervisor smoke is pending.
