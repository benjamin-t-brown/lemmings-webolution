# Arrow-block seams in Now You're Stalking

Playtest 18 H2, **Now You're Stalking** (`E22_KF_1`, node 27). Colored hairlines crossed the red-arrow faces, the steel rail below them, and some wood panels. The tube route now clamps bilinear samples at the edges of this installed level's tile textures. [Playtest ledger](../playtest/2026-11-18-playtest-18.md) · [Arrow close-up, before above after](../../build/stalking-seams-001/retry/desktop-arrows.png)

## Cause and production path

The arrows are painted on the outer tube skin. The effective archive supplies 128×128 `OUT_E22_KF_1_{5,6}_{1,2}HI.BMP` tiles, materials 13, 14, 21, and 22. Their painted blocks span buckets 20–25 at bands 1–2. The collision grid carries the directional refusal bits on the terrain, including solid cells `0x05` on one side and `0x09` on the other. `CellMesh` builds layer-1 rectangles with side/top ribbons using the same vertex-key table. `TubeScene` binds the tile by material, splits each quad into two triangles, and submits its tile-local UVs. [Decoded tiles](../../build/stalking-seams-001/arrow-tiles.png) · [Asset and cell census](../../build/stalking-seams-001/tube-probe-before.log)

`TubeScene::build` assigns clamp to loaded tiles under `TEXTURES\CYLINDER\E22_KF_1\`. The draw path is `runApplicationLeg` → `scheduleSceneFrame` → `TubeScene::render` → `drawRouteQuad` → `Raster::triangle`. INN and the three OUT passes pass the selected tile's address mode down to the opaque RGB sampler. A wrapped bilinear tap reaches the bitmap's opposite edge within half a texel of UV 0 or 1. Clamp uses the nearest edge texel there. A ribbon can hold that UV constant across several screen pixels. The sample occurs after pixel coverage and depth acceptance and supplies only RGB. The same depth and ownership writes feed actor occlusion. Simulation and picking use the same state and geometry. [Route draw](../../src/app/TubeScene.cpp) · [RGB sampler](../../src/app/Raster.cpp)

The asset-family scope is provisional. The original requests clamping for the terrain passes. Applying that globally in the previous attempt also changed the established `MM_CLIMB_002` comparison frames and caused 17 `actorcompose` failures. This retry limits the change to the demonstrated H2 defect. The focused rerun passed all 348 checks with the existing assertions. ## Original static evidence

Ghidra 12.1.4 read the registered x86 `Lemmings Revolution.exe`, SHA-256 `32675bdb49866e76502713251fdfd2b09078c2481c72ca22ff68ebf4b3737a2f`. The `0x470FAF` xrefs are `0x43A6BB` and `0x43A908`. Pseudocode and instructions agree on argument 1 before the four terrain calls (`0x43A754`, `0x43A7F4`, `0x43A87C`, `0x43A8FA`), then argument 0. The setter at `0x470FB8..0x470FD8` selects `3`/`1` for stage 0 address state `0x0C` (CLAMP/WRAP). The INN depth bias bracket is at `0x43A6C6` and `0x43A766`. REA closed without a snapshot. `0x463410` uses the shared key lookup `0x43A31D`, with the key built at `0x43C930`. Its UV calls at `0x463512..0x463550` agree with the retained face mapping `(x & 31)/32`, `1-(y & 31)/32`. The reconstructed side and top ribbons already carry the original inset constants `1/512` and `1/128`. The pass order and those UVs are unchanged. The CPU pixel-center edge rule and bilinear sampling remain clone conventions. Exact original raster edge coverage and effective hardware state were outside this static check.
