## Recovered loop

Mode zero selects a 7×7 mask and nonzero selects a 9×9 mask. The code
subtracts half the width from X and Y, wraps X through `0x0040DEC0`, clamps
Y through `0x0040DF50`, and truncates the results to integers. For each
nonzero mask byte it reads the collision cell through `0x0040DE60`. Cells
with any of bits `0x2`, `0x200`, or `0x800` are left unchanged. Otherwise an
occupied cell (bit `0x1`) at X and Y divisible by four enters the object
creation branch, and the cell is then cleared to zero. X advances modulo
256 within each row; Y advances by one after each row and stops when it
reaches world height. The original later calls `0x0043B0A1` with the affected
rectangle and creates visual objects unconditionally.

The later [complete terrain-blast recovery](terrain_blast.md) now implements
the surrounding debris, notification and particle/entity orchestration, with
its own full-routine native comparisons and explicit graphics boundaries.
The remainder of this note records the earlier isolated grid-loop scope.

`clear_terrain_blast_cells` ports the grid changes and reports potential
object-creation sites through a callback. The object constructors, redraw,
sound, and other effects in the full routine remain unrecovered.

## Verification and limits

The exact full-body and mask bytes are pinned in the verifier. The source
builds on x64 and x86 and has constructed tests for mask shape, protected
flags, object sites, and X wrap. A 32-bit offline oracle maps verified
original code and data bytes at their PE addresses, then redirects the
instruction at `0x0043F830` (the loop exit) to the original epilogue at
`0x0043FA1C`. This preserves the original loop instructions and stack
unwind while skipping later visual and object work. In 3,000 generated
grids with world heights from 1 through 96, the resulting complete
collision-cell arrays matched the recovered function for both masks,
protected cells, X wrap, and unaligned occupied cells. Aligned occupied
cells would invoke object construction and are
excluded from this differential. No live-game comparison has been made.
The source requires a positive world height and valid cell storage; the
native routine does not check those conditions.
