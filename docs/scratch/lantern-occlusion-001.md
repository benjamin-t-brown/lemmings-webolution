# lantern-occlusion-001 · Exit lantern occlusion

Playtest 25 Q14 reported lemmings disappearing beside the exit lantern on **Penelope Lem Stop** (`M04_KF_1`, node 34), viewed from the left with the balloon on the right. The occluder is `sprite_Light02_additive8`, LVL record `0xB473B`, a visible Secondary type-2 branch-0 billboard using `MODELS\BG_TREE04\LIGHT02` and selector 2 (ONE/ONE). The clone drew it with alpha test disabled, strict Less depth testing and depth writes enabled. At step 9444, yaw 187, pixel (460, 398) kept its RGB yet went from scene depth 357.124 to 334.567. The upright actor plane was at 349.664, so the new scene depth rejected that pixel. The same billboard hid all 117 drawable actor pixels, including 49 where RGB was unchanged.
