# Touch camera controls

The November 23 mobile request V2 covers the shared level input path. SDL previously translated a finger into a left mouse button, so a swipe moved the view only in examine pause and a pinch had no zoom command. This review revision addresses two source-traced failures in the first adapter on One Way Ticket (`MM_ALL_8_001`). A second threshold crossing could replace the first in the same poll, and a 200 ms fast-forward press could become a tap if its release arrived before the frame's hold check. ## Production path

`SdlWindow` disables SDL mouse/touch synthesis, filters touch-originated mouse events and maps normalized contacts into presentation coordinates. `TouchInput` recognizes taps, drags, holds and pinches. Its provisional thresholds are 8 presentation pixels of slop, a 1.20× pinch ratio, a 180 ms hold deadline and a 300 ms tap limit. A second contact clears a pending tap or drag and ends an active hold. [SDL adapter](../../src/app/SdlWindow.hpp) · [Recognizer](../../src/app/TouchInput.cpp)

`runApplicationLeg` routes taps through the existing left-button handlers and scene drags through `beginCameraDrag`, `pending.mouse` and `endCameraDrag`. The level loop checks for a due hold before handling each finger event, using that event's timestamp. Its idle clock is sampled before polling so the hold check cannot pass a newly queued event. The existing fast-forward plate path follows the finger when it slides off and back on. The frontend routes taps through its left-button path. [Level input](../../src/app/main.cpp#L1566) · [Frontend input](../../src/app/FrontendWindow.cpp#L94)

The fixed camera tick drains pinch transitions in order. Each compares its requested direction with the current zoom state, resolves its midpoint anchor through `zoomAtPointer` and uses the same controller toggle as keyboard and wheel zoom. Keyboard and wheel retain their coalesced pending edge, which runs first if both input types reach the same tick. Flip and motion still advance once per tick. [Camera tick](../../src/app/main.cpp#L1702) · [Controller](../../src/app/CameraInput.cpp#L40)
