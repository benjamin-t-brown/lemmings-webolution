# Windows release package

Playtest 25 Q3 asks for a Windows zip that starts with the player's archives or disc image. Q9 adds the GitHub Actions release button. The source trace showed startup choosing an explicit path, the environment, or a directory relative to the working directory. A missing base surfaced as a raw archive error, and `AssetLibrary::open` treated a missing patch as optional. [Ledger](../playtest/2026-11-21-playtest-25.md) · [Prior entry point](../../build/windows-release-001/main-before.cpp)

`runApplication` now calls `locateGameData`, then opens both archives through `AssetLibrary::openRequired` before creating the frontend session. It reuses that library through the connected route. Lookup goes from `--game-dir` to `WEBOLUTION_GAME_DIR`, the exe directory, the per-user disc cache, a CD image beside the exe, and the working-directory fallback. Missing and invalid boxes produce a distinct startup message on stderr and one SDL dialog on a desktop driver. The dummy driver takes the stderr path.

The desktop lookup and cache are clone additions. The ISO reader supports 2048-byte sectors, raw 2352-byte sectors with data at offset 16 or 24, and Joliet names. The retained disc layout gives `CD001` at byte 37657, the base at LBA 22434, root patch at LBA 180517, and `LEMMIN~1/LEMPATCH.EXE` at LBA 207663. The RAR marker is at `0x4620` in that SFX. The reader prefers the RAR 2.0 patch and uses the root patch when the SFX is absent. It rejects multi-extent or interleaved files. Windows clears abandoned staging on the next import and publishes a complete validated pair to `%LOCALAPPDATA%\LemmingsWebolution\GameData` in one directory rename. For multiple images, the first successful import in filename order supplies the reusable cache. [Retained static disc evidence](../../build/disc-unrar-001/disc-layout.txt)

The public overlay adds the Windows workflow, `RELEASING.md`, and the package README. GitHub Actions builds from the tag's commit on public main and attaches the x64 zip and checksum with generated notes. The dispatch entry validates a new semantic version and creates its tag after the package check. CMake installs the executable, the DLLs found by the MinGW dependency scan, the package README and the MIT license. `WEBOLUTION_VERSION` supplies the CLI, SDL title and PE resource strings.
