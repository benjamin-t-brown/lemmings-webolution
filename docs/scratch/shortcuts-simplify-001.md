# Simplify Keyboard Shortcuts

Playtest 30 W6 reported too many controls on the web build's Keyboard Shortcuts screen. W7 supplied the wording “Examine Level.” The clone's before frames show that Options opened one screen with two columns of sections. The after frames show five rows for 1 to 8, P, Enter / Pause/Break, Keypad Enter and Escape, with “Examine Level” on both Examine rows. The page retains its title, menu font and Back plate. The footer key hint was removed to keep the page to those five shortcut listings.
