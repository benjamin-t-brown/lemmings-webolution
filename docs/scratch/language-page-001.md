## Clone and checks

- `runFrontendWindow` routes SDL clicks and touch taps through `FrontendSession::click`, and Return through `pressReturn`. `shell::Frontend::press` replaces the page and resets focus to row 0. `FrontendSession::create` renders the highlighted English choice with the shared plate renderer and first-row geometry. Choosing English by click, touch, or Return returns to the main menu. Escape returns without writing a choice. [Task-only diff](../../build/language-page-001/implementation.diff) · [Focused main menu](../../build/language-page-001/main-menu-language-focused.png) · [Language page](../../build/language-page-001/language-page.png)
- `loadEnglishStrings` fixes the production table to UK across the frontend, map, level menu, entry cue and results. Production already used UK at every string-table call, so there were no alternate-language branches to remove. Generic parsing, codepages and developer tools still support asset inspection. The clone records explicit English selections as two bytes, `UK`, in `%LOCALAPPDATA%\LemmingsWebolution\Language.dat` through the guarded atomic `FileSaveSink`. Its display has no stored-language dependency. The SDL probe started with a `FRENCH` sidecar and `GERMAN` legacy progress, showed English, preserved the sidecar on Escape, and wrote `UK` on selection. The original-format save and legacy progress bytes matched the seeded files throughout. Touch was exercised through queued SDL finger events. [SDL and save log](../../build/language-page-001/frontend-input.log)
- `frontendsession` used to require Return to leave row 2 unsupported and clicking its center to miss. Those two assertions now require the Language page with focus on English and progress preserved. The registered UCRT64 `smoke_tests` build passed. All 95 main smoke-labelled tests passed across the focused and remaining runs, including the 102-level sweep.
