# entry-backdrop-rect-001 · Forest backdrop during level entry

Playtest 18 H3 reported an opaque blue rectangle during entry into **Now you're stalking** (`E22_KF_1`, node 27). I reproduced it through **Play Current Game → map node 27** with the clone's source-built framebuffer observer and a private seeded save. The rectangle covered most of the opening frame and was still visible at 0.875 s. It was gone by the 1.0 s sample, just before the rotation began. The four local `E22_KF_1` attempts end with 0–1 of 49 saved and contain no framebuffer output. The Primary `Spooky_Forest` tree's `bmerge29` node at LVL offset `0x5DF37` has 16 kind-7 quads in block `0x90D77`. Records `0x9185A` and `0x91A02` wrote the blue pixels at the opening pose. Their material at `0x6D5A6` selects blend 0 and maps `TEXTURES\MODELS\BG_TREE04\BACKGROUND_01.BMP`, a 256×128 bitmap from `lemmings.box` at `0x23A5708`. Its decoded texels and both records' vertex alphas are all 255. The texture has a plain basename and lacks a patch override or sibling ALF. The near panels were writing color and depth in front of the playfield. The lanterns from `lantern-glow-001` are separate Secondary type-2 `LIGHT02` billboards with additive selector 2. **Changed file.** `src/app/BackdropScene.cpp` extends the existing authored-normal predicate to kind-7 forest backdrop quads using this material. The production path is `runApplicationLeg → CameraIntro::pose → renderFrame → BackdropScene::renderStage(Primary) → drawMesh → passesFacingPredicate`. Back-facing panels skip raster submission so the player can see the level, and the panels facing the camera draw the forest behind it. The same predicate runs at any camera pose.
