invocation selects that role in [AGENTS.md](../../AGENTS.md); it does not select project
facilitation and does not authorize dispatching rounds or editing the queue.

Launch or steer a facilitator only as the user directs, using
[model mapping](../../docs/ROLES.md) for its client. Report gate movement, budgets,
guardrails and decisions that need the user.
