## Read from the machine code

`0x00430C9C` loops from index zero to the count at object `+0x78`. Its
local lower/upper `double[3]` arrays start at object `+0x78` and `+0x88`;
each vector's data pointer is at `+0xC` and elements are 24 bytes. It
reads an actor point from actor `+8` and facing from actor `+0x40`.
Facing `-1` and `+1` have duplicate comparison chains; any other facing
returns `-1`. Each lower and upper local coordinate is added to the object
coordinates at `+0x48`, `+0x50`, `+0x58`. The first containing box index is
returned, or `-1` when none matches.

The lower tests use `FCOMP` plus `TEST AH,0x41` and accept less-than,
equal, or unordered. The upper tests use `TEST AH,1` and reject less-than
or unordered. This makes finite box faces inclusive, while a NaN lower
sum can pass and a NaN upper sum fails. The C++ source preserves the
comparison order and uses `long double` for the x87 sum before comparing
against the actor's `double` point.

`0x00430EE4` walks the same retained actor list as `0x00430C33`, calls
`0x00430C9C` for each actor, and returns the first actor whose box index
is not `-1`, or zero at the list end.

## Scope and unknowns

These are static READ findings with constructed unit tests and an offline
original-byte differential check, not live game measurements. Both x64 and
x86 MinGW builds pass. The x86 helper maps verified bytes for `0x00430C9C`
and its two self-contained callees at their original virtual addresses in
an owned process. It compared 14,116 cases (special values and deterministic
numeric inputs) against the recovered C++ with no mismatches. A second owned
x86 helper maps `0x00430EE4`, the global list helpers, and the box test at
their native addresses; 10,000 constructed actor-list searches matched the
C++ first-match result. Exact game
x87 precision and rounding control word at this call site remain unknown;
the test establishes equivalence under the helper process's FPU mode.
Constructed tests cover facing, box order, inclusive faces, NaN asymmetry,
empty and first-match traversal, and an extended-precision boundary.
The relation between
these local boxes and the object-wide bounds at `0x00430BA1` remains to
be established by caller or producer analysis.
