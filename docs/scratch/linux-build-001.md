# Linux build and release

Playtest 25 Q10 requests Linux builds and extends the desktop release from Q3 and Q9. In the inherited startup path, lowercase loose-box names reached filesystem calls directly, so `LEMMINGS.BOX` and `PATCH.BOX` would be missed on a case-sensitive filesystem. The per-user path also accepted a relative `XDG_DATA_HOME`, which could put data under the launch directory. The production path is `runApplication` → `locateGameData` → `AssetLibrary::openRequired` for the connected frontend, and `runApplication` → `AssetLibrary::open` for replay and diagnostic routes. CD startup goes through `installDiscGameData`. The cache, save, and sound settings share the root from `localAppDataDirectory`. The packaged startup check reached the frontend, and the promoted Just Climb (`MM_CLIMB_002`) recording exercised the replay path. [Ledger](../playtest/2026-11-21-playtest-25.md) · [Startup log](../../build/linux-build-001/windows-package-check.log)

The release is a clone addition. Retained static evidence for the registered x86 EXE, SHA-256 `32675bdb49866e76502713251fdfd2b09078c2481c72ca22ff68ebf4b3737a2f`, records the save writer at `0x0045F94D..0x0045FADD`. The disc layout gives the base at LBA 22434, the root patch at LBA 180517, and the patch installer at LBA 207663 with its RAR marker at `0x4620`. The task reuses the save codec and disc reader. The original EXE was never launched. [Retained save evidence](../../build/emscripten-build-001/rea-save.json) · [Retained disc layout](../../build/disc-unrar-001/disc-layout.txt)
